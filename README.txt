LUPA — primera versión móvil

Contenido:
- index.html: aplicación
- manifest.json: instalación como app (PWA)
- sw.js: funcionamiento offline
- iconos SVG

Uso:
1. Servir esta carpeta desde HTTPS para instalarla como PWA.
2. En Android: abrir en Chrome y elegir "Instalar app".
3. En iPhone/iPad: abrir en Safari, Compartir > Añadir a pantalla de inicio.

La versión actual contiene 25 curiosidades y guarda localmente el contador de descubrimientos.
